How the AI works here

No backend, no build step, no API keys required to start.

1. Demo AI (default). Every task ships with a built-in generator in local-ai.js that runs 100% in the browser — extractive summarization, template-based decks, quiz construction, a study-timetable algorithm and more. Everything is functional out of the box.
2. Live AI (optional). Click 🔑 AI Key and paste an OpenAI API key. The key is stored only in your browser's localStorage and sent only to api.openai.com — never to GitHub. Every task then uses real AI with structured prompts (JSON mode where needed). If the API fails, the page falls back to demo AI automatically.
3. One shared dispatcher. ai.js routes every task through generateAI(task, input), so swapping providers later means editing one file.

Run it locally

Clone & serve. git clone <your-repo-url> && cd ai-classroom && python3 -m http.server 8000 — then open http://localhost:8000. (Any static server works; opening files directly also works except where noted.)
Deploy to GitHub Pages. Push to GitHub → Settings → Pages → Deploy from a branch → main / (root). The .nojekyll file is included so Pages serves everything as-is. Your site goes live at https://<user>.github.io/<repo>/.
