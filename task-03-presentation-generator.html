Task 3

AI Presentation Generator

Type any topic, pick a slide count, and get a ready-to-present slide deck. Flip through it, then print it to PDF.

Tip: use ← → arrow keys to move between slides.

How to use this task
  1. Enter a topic and choose how many slides you want.
  2. Click ✨ Generate Slides to build the deck.
  3. Use Prev/Next (or arrow keys) to rehearse, then 🖨️ Print / Save PDF.
  4. Connect an OpenAI key (🔑 AI Key) for topic-specific, real AI slides.
